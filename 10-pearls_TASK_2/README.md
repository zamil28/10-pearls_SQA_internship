## 📋 Project Overview

This repository contains the test planning and test execution documentation for an **Online Book Store** system, developed as part of a QA internship assignment. The purpose of this project is to demonstrate the ability to prepare a high-level test plan, design test cases, manage them in a test management tool (Testworthy), execute tests, and generate professional test execution reports.

## 🎯 Learning Objectives

- Learn to write effective test cases
- Understand test planning and execution
- Learn how to manage test suites in Testworthy
- Learn to write a high-level test plan document
- Understand classification of test cases such as Smoke, Regression, Negative, and Automation Candidates
- Understand how to track and report test execution results

## 🗂️ Repository Contents

| File | Description |
|---|---|
| `High-Level_Test_Plan.docx` | High-level test plan covering introduction, scope, objectives, test environment, testing types, entry/exit criteria, risks & assumptions, and deliverables |
| `OnlineBookStore_TestCases.xlsx` | Designed test cases with Test Case ID, Scenario, Steps, Expected Result, Priority, and Test Type (Smoke / Regression / Negative / Automation Candidate) |
| `Test_Execution_Report.pdf` | Test execution report generated from Testworthy after running the test suite |
| `OnlineBookStore_TestCases_Export.csv` | Exported test cases and execution results from Testworthy in CSV format |

## 📖 Document Structure

### Test Plan (`High-Level_Test_Plan.docx`)
1. **Introduction**
2. **Scope of Testing**
3. **Testing Objectives**
4. **Test Environment**
5. **Testing Types**
6. **Entry and Exit Criteria**
7. **Risks and Assumptions**
8. **Test Deliverables**

### Test Cases (`OnlineBookStore_TestCases.xlsx`)
13 test cases covering all core workflows of the Online Book Store system:
- User Registration
- Login and Authentication
- Browse Book Catalog
- Search Books
- View Book Details
- Add Books to Cart
- Checkout Process
- Order Confirmation

Each test case includes: Test Case ID, Test Scenario, Test Steps, Expected Result, Priority, and Test Type classification.

## 🛠️ Tools & Techniques Used

- **Testworthy** — test suite creation, test case management, execution tracking, and reporting
- **Manual testing techniques** — functional, negative, regression, and smoke testing
- **Test classification** — Smoke, Regression, Negative, Automation Candidate
